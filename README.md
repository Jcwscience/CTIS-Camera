# CTIS-Camera

This repository contains the mechanical and hardware documentation for a
Computed Tomography Imaging Spectrometer (CTIS) camera, along with space for
local measurements. The software implementation has been cleared so it can be
started again from a clean slate.

## Repository contents

- `hardware/cad/` — editable mechanical designs and drawings.
- `hardware/stl/` — printable part exports.
- `hardware/optics/` — lens, disperser, sensor, and optical layout specifications.
- `hardware/electronics/` — schematics, wiring, and component information.
- `data/` — guidance for local measurements and generated data.

See [the hardware overview](hardware/README.md) for build notes and the bill of
materials. Record units, component revisions, and source links as the design
progresses.

## Software restart

There is currently no software package, dependency configuration, or test suite in
the repository. Add new software and its environment instructions when ready.
